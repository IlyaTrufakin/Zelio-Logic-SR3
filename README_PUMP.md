# Программа управления скважинным насосом для Zelio Logic SR3 B262BD

## 1. Спецификация оборудования и входов/выходов

| Канал | Тип | Назначение | Описание работы |
|---|---|---|---|
| **I1** | Дискретный вход (24V DC) | **Датчик давления (НО)** | Нормально-разомкнутый контакт реле давления (2...3 бар).<br>• При давлении **< 2 бар**: контакт **разомкнут** (`I1 = 0`) $\to$ запрос на включение насоса.<br>• При давлении **≥ 3 бар**: контакт **замкнут** (`I1 = 1`) $\to$ команда на останов насоса. |
| **I2** | Дискретный вход (24V DC) | **Кнопка сброса аварии / принудительный пуск** | Внешняя кнопка без фиксации (НО). Сбрасывает триггер аварии B05 и производит пуск насоса. |
| **I3** | Дискретный вход (24V DC) | **Переключатель режимов (тумблер таймаута)** | **Выбор защитного таймаута аварии:**<br>• **НЕТ СИГНАЛА (`I3 = 0`)** $\to$ **КОРОТКИЙ ТАЙМАУТ (4 минуты)**: стандартный домашний режим, контроль гидробака и защита от сухого хода.<br>• **ЕСТЬ СИГНАЛ (`I3 = 1`)** $\to$ **ДЛИННЫЙ ТАЙМАУТ (90 минут)**: режим длительного водоразбора (полив участка, набор большой ванны, мытье посуды). |
| **Q1** | Транзисторный выход (24V DC, 0.5A) | **Твердотельное реле (ТТР)** | Выход +24 В на управляющий вход однофазного ТТР скважинного насоса. |
| **Q2** | Транзисторный выход (24V DC, 0.5A) | **Сигнальная лампа работы насоса** | Включается строго синхронно с насосом (`Q2 = Q1`). Насос качает $\to$ лампа горит. Насос остановлен $\to$ лампа погашена. |

## 3. Таблица функциональных блоков FBD (для сборки в ZelioSoft 2)

| Блок | Тип в палитре ZelioSoft | Параметры и уставки (двойной клик на блоке) | Назначение в схеме |
|---|---|---|---|
| **B01** | `FBD` $\to$ `TIMER A/C` | **Функция A/C**: $Ta = 3.0\text{ s}$, $Tb = 5.0\text{ s}$ | Фильтр гидроударов и гистерезис давления (3с задержка пуска, 5с докачка бака). |
| **B02** | `FBD` $\to$ `BISTABLE` | **RS-триггер** (Set / Reset) | Главный триггер пуска/останова насоса. Выход подключен к `Q1` (ТТР) и `Q2` (лампа). |
| **B03** | `FBD` $\to$ `TIMER A/C` | **Функция A (Delay ON)**: $Ta = 240.0\text{ s}$ (4 мин) | Короткий таймаут сухого хода / порыва трубы при обычном режиме (`I3 = 0`). |
| **B04** | `FBD` $\to$ `TIMER Li` | **Blinker**: $T_{high} = 30.0\text{ s}$, $T_{low} = 30.0\text{ s}$ | Минутный тактовый генератор (1 импульс в 60 секунд) для отсчета времени полива. |
| **B06** | `FBD` $\to$ `PRESET COUNT` | **Preset = 90**, счет по переднему фронту | Длинный таймаут полива/ванны (90 минут) при включенном тумблере (`I3 = 1`). |
| **B05** | `FBD` $\to$ `BISTABLE` | **RS-триггер аварии** | Защита от сухого хода. Блокирует насос при превышении таймаута B03 или B06. Сброс по `I2`. |
| **LCD** | `OUT` $\to$ `LCD BACKLIGHT`| Подсветка дисплея | Активируется выходом триггера аварии `B05` (при аварии экран светится в щите). |

## 4. Электрическая схема подключения

```text
                 Блок питания 24 В DC
                 +24V       0V (GND)
                  |            |
  (+) клемма ПЛК -+            |
  (-) клемма ПЛК --------------+
                  |            |
                  +-------+    |
                  |       |    |
  I1 (Вход ПЛК) <-+-[Реле давления (НО)]
                  |       |
  I2 (Вход ПЛК) <-+-[Кнопка Пуск/Сброс (НО)]
                  |
  I3 (Вход ПЛК) <---[Тумблер "Полив / Длинный таймаут"]
  
  Q1 (Выход ПЛК) -------------> Вход (+) ТТР (3-32V DC)
  0V (GND) -------------------> Вход (-) ТТР (GND)

  Q2 (Выход ПЛК) -------------> Лампа работы насоса (+)
  0V (GND) -------------------> Лампа работы насоса (-)

------------------ СИЛОВАЯ ЦЕПЬ 230 В ------------------
  Фаза L (~230V) --> [Автомат C10-16A] --> Клемма 1 ТТР
  Клемма 2 ТТР --------------------------> Фазный провод насоса
  Нейтраль N ----------------------------> Нулевой провод насоса
  Заземление PE -------------------------> Корпус / заземление насоса
```

### Защита твердотельного реле (ТТР):
* Параллельно силовым клеммам 1-2 ТТР обязательно установить:
  1. **Варистор 20D471K** (470 В) для защиты от индуктивных выбросов при отключении двигателя.
  2. **RC-цепь (Snubber)**: конденсатор 0.1 мкФ 630В + резистор 100 Ом 2 Вт.
